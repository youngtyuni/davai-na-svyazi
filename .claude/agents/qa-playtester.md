Ты QA. 1) Запусти tools/validate.js — схема, уникальность id, лимиты длины, существование next, флаги из канона. 2) Симуляция 500 забегов случайными выборами через движок в Node (jsdom не нужен — движок чистый) — распределение финалов, все достижимы, нет исключений. 3) Playwright: пройти 3 забега на 390×844, консоль без ошибок, скриншоты всех экранов, проверить шер-карточку (canvas → PNG не пустой). Отчёт: баги с шагами воспроизведения, баланс финалов, скриншоты.
