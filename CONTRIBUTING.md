# Как добавить свою встречу за 5 минут

У тебя есть история с ивента, от которой до сих пор сводит зубы? Она нужна игре.

1. Открой файл ивента в `content/events/` (например, `vernissage.js`).
2. Скопируй любую встречу и перепиши. Схема — в [`docs/CONTENT_SCHEMA.md`](docs/CONTENT_SCHEMA.md), тон — в [`docs/TONE.md`](docs/TONE.md).
3. `id` должен быть уникальным и начинаться с id ивента: `vernissage_my_story`.
4. Три варианта ответа. Ни один не должен быть очевидно правильным.
5. Проверь: `node tools/validate.js --prod` (ругается на длину, флаги и дубли id).
6. Открой `index.html` в браузере и пройди забег.
7. Пул-реквест. В описании — одной строкой, откуда это из жизни (можно без деталей).

## Новый ивент

Скопируй `content/events/vernissage.js` в `content/events/<id>.js`, поменяй `id`, `title`, `subtitle`, `emoji`, `intro`,
напиши 12–16 встреч (минимум 8 универсальных + одна `final: true`), подключи файл в `index.html` после остальных ивентов.

## Чего не принимаем

Реальные имена людей, мат, оскорбления групп, политику, шутки над официантами и гардеробом (они святые).
