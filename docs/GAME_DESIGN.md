# «ДАВАЙ НА СВЯЗИ» — геймдизайн-документ

Браузерный симулятор нетворкинга в креативных индустриях. Одна вечеринка — один забег (3–5 минут).
Игрок выбирает роль, попадает на индустриальный ивент, общается с NPC, выбирает реплики,
следит за тремя шкалами и в конце получает архетип + шер-карточку.

## Ядро

- **Платформа:** статический сайт (HTML/CSS/JS без сборки), хостится на GitHub Pages, работает с file://.
- **Язык:** русский. Весь UI и контент — на русском.
- **Формат сессии:** роль → ивент → интро → 8 встреч → финал → шер-карточка.
- **Mobile-first:** ссылку присылают в Telegram, открывают с телефона. Всё тапается большим пальцем.

## Шкалы (0–100)

| Шкала | Ключ | Старт | Что значит |
|---|---|---|---|
| 🔋 Батарейка | `energy` | 70 | Социальная энергия. 0 → финал «Батарейка села». |
| 😬 Кринж | `cringe` | 10 | Накопленная неловкость. 100 → финал «Человек-момент». |
| ✨ Клаут | `clout` | 30 | Как тебя воспринимает тусовка. Влияет на архетип. |

Плюс список **контактов**: каждый контакт имеет `kind`: `real` (напишет) или `empty` (не напишет никогда).
В финале показывается «Контактов: N. Ответят: M».

Кнопка **«Уйти по-английски»** доступна всегда → мгновенный финал `english_exit`.

Каждый ивент содержит 12–16 встреч. За забег показываются 8: сначала гарантированно
подмешиваются 1–2 ролевых встречи для роли игрока (если есть), остальное — универсальные, случайно.
Встречи с полем `final: true` появляются последними (кульминация).

## Встреча (`encounter`)

NPC-бейдж (имя + абсурдно длинный титул) + ситуация + 3 варианта ответа.
Каждый вариант даёт исход-текст, дельты шкал, опционально контакт, флаги и `next` (цепочка).

## Финалы (`endings`) — приоритет сверху вниз

1. `cringe_max` — кринж ≥ 100 во время забега → «Человек-момент».
2. `energy_zero` — батарейка ≤ 0 → «Батарейка села».
3. `english_exit` — нажал «Уйти по-английски».
4. `free_worker` — флаг `free_work` ≥ 2 → «Работаю за экспозицию».
5. `pitcher` — флаг `pitched` ≥ 2 → «Человек-питч».
6. `found_people` — ≥ 2 реальных контакта и кринж < 70 → «Нашёл своих».
7. `king` — контактов ≥ 4 и реальных 0 → «Король нетворкинга».
8. `legend` — клаут ≥ 70 и кринж ≥ 60 → «Легенда вечера».
9. `ghost` — клаут < 40 и контактов ≤ 1 → «Невидимка».
10. `pro` — клаут ≥ 60 и кринж < 50 → «Тихий профессионал».
11. `normal` — всё остальное → «Нормально пообщался» (самый редкий исход).

## Ачивки (`achievements`) — считаются по флагам в конце

Флаги — свободные строки, которые ставят варианты ответов. Канонический список:
`said_davai` (сказал «давай на связи»), `prosecco` (взял бокал), `lied` (приукрасил занятость),
`pitched` (запитчил свой проект), `free_work` (согласился на «за опыт»), `forgot_name` (забыл имя),
`phone_hide` (ушёл в телефон), `toilet` (спрятался в туалете), `ai_talk` (разговор про нейросети),
`honest` (сказал правду), `ghosted` (пообещал написать и не напишешь), `complained` (пожаловался на индустрию),
`fake_laugh` (засмеялся не поняв шутку), `ask_budget` (спросил про бюджет), `burnout` (признался в выгорании).

## Шер-карточка

Canvas PNG 1080×1920 (формат сторис): название игры, архетип, одна строка-приговор, 3 шкалы, «контактов / ответят»,
до 3 ачивок, URL. Кнопки: «Скачать картинку», «Скопировать текст», «Поделиться» (Web Share API),
«В Telegram» (t.me/share/url). Текстовый вариант — короткий, с эмодзи-полосками, как в Wordle.

## Визуальный стиль

Acid-zine: чёрный фон `#0B0B0B`, кислотный лайм `#D8FF3B`, розовый `#FF3EA5`, бумага `#F3F0E6`, синий `#3B5BFF`.
Заголовки — Unbounded (Google Fonts, кириллица), текст — Inter Tight / системный.
Метафора NPC — конференц-бейдж на ленте «ПРИВЕТ, Я …». Стикеры, лёгкие повороты, жирные рамки.
Анимации: бейдж влетает, шкала кринжа трясётся при росте, батарейка мигает < 20.
