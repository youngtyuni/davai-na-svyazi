# Стратегия производства «ДАВАЙ НА СВЯЗИ»

## Цель

Вирусная браузерная игра про нетворкинг в креативных индустриях: 3–5 минут, одна ссылка, результат,
которым хочется поделиться. Хостится на GitHub Pages, форкается, пополняется контентом через пул-реквесты.

## Команда агентов (каждая роль — свой агент, определения в `.claude/agents/`)

| Роль | Агент | За что отвечает | Вход | Выход |
|---|---|---|---|---|
| Продюсер / геймдиректор | главная сессия | видение, спек, приоритеты, интеграция, финальная приёмка | бриф | репозиторий |
| Индустриальные ресёрчеры ×10 | `industry-researcher` | реальные боли, мемы, фразы, архетипы, истории по секторам: галереи, музыка, форумы/гранты, реклама/агентства, кино/продакшн, фриланс/дизайн, ивент-индустрия, креативные директора, креаторы + телеграм-каналы, медиа-арт | бриф по сектору | `research/<sector>.md` |
| Геймдизайнер | `game-designer` (в этой итерации — главная сессия) | механики, шкалы, финалы, баланс дельт | ресёрч | `docs/GAME_DESIGN.md` |

## Пайплайн

1. **Фундамент (день 0).** Спек, схема контента, тон, стиль — фиксируются до любого контента, чтобы все работали параллельно.
2. **Ресёрч (параллельно ×10).** Каждый ресёрчер ищет по своему сектору: Telegram-каналы и мемы индустрии, треды, статьи
   про боли фрилансеров/агентств/галерей, зарубежные мемы (Clients From Hell, exposure bucks, «make the logo bigger»),
   типовые фразы с нетворкингов. Формат — структурированный md: боли / фразы / архетипы NPC / микроситуации / истории.
3. **Движок (параллельно с ресёрчем).** Инженер строит engine по схеме с тестовым контентом. Не зависит от ресёрча.
4. **Сценарии (параллельно ×11).** Каждый сценарист получает ресёрч своего сектора + общий дайджест + тон + схему
   и пишет 12–16 встреч. Контрактом служит схема: файлы подключаются без правок.
5. **Редактура юмора.** Один редактор читает весь корпус: убирает повторы, усиливает панчлайны, выравнивает тон, проверяет запреты.
6. **Интеграция и QA.** Валидатор схемы (`tools/validate.js`), автоплейтест случайными выборами ×200 (все финалы достижимы,
   нет крашей, баланс: доля каждого финала), ручные скриншоты на мобильном вьюпорте.
7. **Упаковка.** README, OG-картинка, шер-тексты, GitHub Pages workflow, лицензия, гайд «как добавить свою встречу».

## Исследовательский план (что собираем)

- Фразы-клише нетворкинга и индустриальный жаргон (RU + EN).
- Боли по секторам: оплата, «за опыт», правки, тендеры, гранты, кураторы, техрайдеры, монтаж в ночь, дедлайны, выгорание, нейросети.
- Архетипы людей на ивентах: founder-визионер, куратор с текстом, арт-директор «мы семья», музыкант с демо, человек с айпадом, «я из комьюнити».
- Микроситуации social awkwardness: забыл имя, стоишь один, застрял, не понял шутку, фальшивый смех, «давай на связи».
- Что уже вирусилось: форматы шер-карточек (Wordle, Spotify Wrapped, «какой ты …»), чтобы финал был шерабельным.

## Критерии успеха

**Продукт**
- Забег 3–5 минут, 8 встреч, без тупиков и крашей (200 автопрогонов — 0 ошибок).
- ≥ 130 встреч суммарно, 11 ивентов, 10 ролей, 11 финалов, все финалы достижимы (проверено симуляцией).
- Работает на телефоне (375px), с file:// и с GitHub Pages, без сборки, без зависимостей.
- Шер-карточка генерируется за < 1 с, скачивается, копируется текстом, уходит в Telegram.

**Контент**
- Каждая встреча проходит чек-лист из `docs/TONE.md`.
- Нет повторяющихся шуток, нет запрещённого.
- Редактор юмора оценил каждую встречу ≥ 4/5, слабые переписаны.

**Виральность**
- Результат — архетип с приговором в одну строку, который хочется отправить коллеге.
- OG-превью ссылки работает в Telegram/iMessage.
- README за 10 секунд объясняет, что это, и как добавить свою встречу через PR.
