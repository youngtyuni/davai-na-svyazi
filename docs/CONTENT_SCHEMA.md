# Схема контента

Каждый ивент — отдельный файл `content/events/<id>.js`, который регистрирует себя в глобальном реестре.
Никаких импортов/сборки — обычный `<script>`.

```js
// content/events/vernissage.js
window.GAME_CONTENT = window.GAME_CONTENT || { events: [] };
window.GAME_CONTENT.events.push({
  id: "vernissage",
  title: "Открытие выставки",
  subtitle: "Галерея «Пространство». Просекко тёплое, куратор напряжён.",
  where: "на открытии выставки",  // опционально: предложный падеж для «А ты кто на открытии выставки?» в шер-тексте
  emoji: "🖼️",
  intro: "2–3 предложения, задающие сцену. Хлестко, с деталью.",
  picks: 8,                      // сколько встреч за забег
  time: ["19:00", "01:30"],     // опционально: время начала и конца вечера, HUD интерполирует по встречам
  encounters: [
    {
      id: "vernissage_curator",   // уникальный, с префиксом ивента
      roles: ["artist"],          // опционально. Нет поля = универсальная встреча
      final: false,               // опционально: показать последней (callback на anchor-NPC по имени)
      anchor: false,              // опционально: ровно одна на ивент, всегда первая, её NPC — сквозной
      phase: "late",              // опционально: "late" — вторая половина вечера; без поля — любая
      npc: {
        name: "Полина",
        title: "Куратор, исследовательница, «работаю с памятью»",   // до 70 символов
        emoji: "🥂"
      },
      text: "Что говорит NPC или что происходит. До 280 символов. Узнаваемая деталь обязательна.",
      options: [
        {
          text: "Реплика игрока (до 90 символов)",
          result: "Что произошло. 1–2 предложения, панчлайн в конце. До 220 символов.",
          energy: -10, cringe: 15, clout: 5,      // любые из трёх, целые числа, можно опускать
          contact: { name: "Полина", title: "куратор", kind: "empty", note: "«напишу на неделе»" }, // опционально
          flags: ["said_davai"],                   // опционально
          next: "vernissage_curator_2"             // опционально: следующая встреча в цепочке (должна существовать, roles не проверяются)
        },
        { /* ... */ },
        { /* ... */ }
      ]
    }
  ]
});
```

## Правила

- `where` — необязательная строка в предложном падеже с предлогом («на афтепати», «на форуме»). Подставляется в вызов «А ты кто {where}?» на шер-карточке и в тексте; без него — «А ты кто?».

- 3 варианта в каждой встрече (иногда 2 или 4 допустимо, но 3 — норма). Ни один вариант не должен быть «очевидно правильным».
- Суммарно за забег из 8 встреч игрок должен реально рисковать и кринжем 100, и батарейкой 0. Типичные дельты: энергия −5…−20, кринж −10…+35, клаут −15…+20.
- `contact.kind`: `real` — редкость (1–2 на ивент), `empty` — норма.
- Встречи-цепочки (`next`) — не длиннее 2 шагов; цепочечная встреча не входит в случайную выборку, если у неё `chained: true`.
- Флаги — только из канонического списка в GAME_DESIGN.md (можно добавлять новые, но тогда их надо добавить в `js/data.js`).
- Текст — русский, «ты», без мата (допустимы «блин», «чёрт»). Никаких реальных имён людей. Бренды-инструменты (Figma, Telegram, Behance) можно.
