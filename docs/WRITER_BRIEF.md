# Бриф сценариста (один ивент — один агент)

Прочитай в этом порядке: `docs/TONE.md`, `docs/CONTENT_SCHEMA.md`, `docs/GAME_DESIGN.md` (роли, флаги, финалы),
`content/events/_sample.js` (формат), затем ресёрч своего сектора и `research/freelance_awkward.md` (универсальная неловкость).

## Что сдать

Файл `content/events/<id>.js` с 14–16 встречами:
- 9–10 универсальных (без `roles`), из них одна `final: true` (кульминация вечера: гардероб, такси, последний бокал, «а ты на афтепати?»).
- 3–4 ролевых (`roles: [...]`) — для ролей, которым этот ивент особенно больно: укажи 1–3 роли на встречу. Роли: designer, event, musician, artist, producer, cd, photo, creator, tgadmin, mediaartist.
- 1–2 цепочки: встреча с `next` + продолжение с `chained: true`.
- 1–2 контакта `kind: "real"` на весь ивент, остальные `empty` с убийственным `note`.
- Используй флаги из канонического списка минимум 8 разных раз.

## Баланс дельт

За 8 встреч игрок должен реально рисковать и кринжем 100, и батарейкой 0, но не умирать на 3-й встрече.
Ориентиры на один вариант: energy −5…−20 (редко +5…+10), cringe −10…+35 (обычно +5…+20), clout −15…+20.
В каждой встрече хотя бы один вариант с cringe ≥ 15 и хотя бы один с energy ≤ −10.

## Проверка перед сдачей

```bash
node tools/validate.js
```
Исправь всё, на что ругается. В ответе: путь к файлу, число встреч, 5 лучших исходов (цитатой).
